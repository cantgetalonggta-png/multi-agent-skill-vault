# Keyword Research Report Template

## 1. Executive Summary
- Primary opportunity
- Top 3 recommended clusters
- Quick wins vs longer-term plays

## 2. Seed and Expansion
- Original seeds
- Expansion methods used
- Total unique terms considered

## 3. Clustered Keywords
For each cluster:
- Cluster name / primary keyword
- Intent
- Member keywords with metrics (volume, KD, CPC if available)
- Suggested content format and angle

## 4. Content Gap Analysis
- Topics competitors cover that the target does not
- Question gaps
- Format gaps (video, tools, comparisons, etc.)

## 5. Prioritized Action List
- Ranked list of next content pieces with rationale
- Estimated effort vs impact

## 6. Raw Data Appendix
- Full table or link to CSV/JSON export
