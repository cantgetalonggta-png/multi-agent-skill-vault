# AI Video Production Checklist

## 1. Intake
- [ ] Brief or script received and understood
- [ ] Target platform(s) and aspect ratio confirmed
- [ ] Length target and hard constraints noted
- [ ] Brand assets, logos, colors, fonts available
- [ ] Reference videos or mood boards collected
- [ ] Voice preferences (gender, tone, language, cloning) specified

## 2. Creative Direction
- [ ] Scene breakdown completed
- [ ] Character / avatar look defined
- [ ] Visual style and lighting language agreed
- [ ] Shot list or keyframe notes prepared
- [ ] Music direction noted

## 3. Generation
- [ ] Primary video clips generated and reviewed
- [ ] Avatar / presenter takes generated and selected
- [ ] Supporting stills and style frames created
- [ ] Voiceover recorded or synthesized and approved
- [ ] Alternate takes retained when useful

## 4. Assembly
- [ ] Timeline built in chosen NLE
- [ ] Picture locked (or near-locked)
- [ ] Audio synced and levels balanced
- [ ] Text, captions, graphics added
- [ ] Music and sound design placed

## 5. Polish
- [ ] Color grade applied
- [ ] Upscale / cleanup performed if needed
- [ ] Final audio mix and loudness check
- [ ] Platform safe zones and text placement verified

## 6. Delivery
- [ ] Master export(s) created at correct specs
- [ ] Platform-specific versions produced
- [ ] Project notes and generation parameters documented
- [ ] Files delivered and confirmed received

Confirm expensive or irreversible steps with the user.
