# Stage Handoff Checklist

Before moving to the next specialized skill, confirm:

- [ ] Previous stage outputs are complete and approved by user
- [ ] Key terminology and messaging captured for consistency
- [ ] Technical parameters (style, voice, visual direction) documented
- [ ] Next skill has the necessary context and assets
- [ ] User has been given the option to adjust direction

After the final stage:
- [ ] All requested assets delivered
- [ ] Cross-asset consistency reviewed
- [ ] Generation notes and parameters archived for future iteration
