# Advanced Lyrics and Structure Planning

## Standard Structure Templates

### Pop / Soul / R&B (approx 80–100 s)
- Intro (4–8 bars)
- Verse 1 (8–16 bars)
- Pre-Chorus (4–8 bars)
- Chorus (8–16 bars)
- Verse 2 (8–16 bars)
- Pre-Chorus
- Chorus
- Bridge (4–8 bars)
- Final Chorus (with ad-libs / lifts)
- Outro / tag

### Hip-Hop / Rap
- Intro / hook teaser
- Verse 1 (16 bars typical)
- Hook / Chorus
- Verse 2
- Hook
- Bridge or breakdown (optional)
- Final hook + outro

### Electronic / Dance
- Intro (build interest)
- Build / riser
- Drop / main section
- Break
- Second drop (variation)
- Outro

## Lyric Workflow

1. Theme + emotional arc (1–2 sentences).
2. Title or central phrase.
3. Section-by-section draft focusing on:
   - Syllable count and stress matching the groove
   - Rhyme scheme consistency
   - Imagery that fits the genre
4. Vocal performance notes per section (delivery, intensity, doubles, harmonies).
5. User review before generation.

## Tips for Better Alignment
- Write lyrics after deciding approximate BPM and groove.
- Mark stressed syllables.
- Leave space for instrumental fills and vocal ad-libs.
- For multilingual tracks, keep language consistent per section or clearly marked.
