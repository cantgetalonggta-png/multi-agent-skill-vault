# Music Production Process Checklist

Use this checklist for every new track request.

## 1. Intake
- [ ] Genre / style clarified
- [ ] Mood / energy level noted
- [ ] Target length (seconds or bars) set
- [ ] Vocals required? Language of lyrics?
- [ ] Reference tracks or constraints provided?
- [ ] Intended platform / use case (streaming, social, background, etc.)

## 2. Planning
- [ ] Structure decided (intro / verse / pre-chorus / chorus / bridge / outro)
- [ ] Approximate BPM and key chosen or left free
- [ ] Instrumentation sketch (if relevant)
- [ ] Quality preset selected

## 3. Generation
- [ ] Prompt written clearly and completely
- [ ] Generation launched with chosen preset
- [ ] Progress monitored (especially for high/max)
- [ ] Initial listen completed

## 4. Iteration (if needed)
- [ ] Specific sections identified for improvement
- [ ] Repaint / cover / regenerate applied
- [ ] Lyrics adjusted if vocal issues present

## 5. Analysis & Enhancement
- [ ] BPM, key, loudness measured
- [ ] Loudness normalized to target platform
- [ ] Noise / artifacts addressed if present
- [ ] Stems separated only if requested

## 6. Export & Delivery
- [ ] Correct sample rate, bit depth, channels
- [ ] Platform-specific loudness and true-peak applied
- [ ] Filename and metadata set
- [ ] Delivered to user with summary of parameters used

## 7. Library
- [ ] Track cataloged with tags, rating, generation notes
- [ ] Reproducibility parameters stored when useful

Confirm long-running steps and any file overwrites with the user.
